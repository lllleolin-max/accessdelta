# Pilot rationale, not validated revenue

Prospective user/buyer: an internal application platform or security team with a finite permission inventory and inherited role-change approval process. The costly task is retaining routine access while removing unintended deployment/resource reachability, especially when membership deletions remove restrictive denies. Existing AWS custom checks and simulation show policy review is an established workflow; they do not validate demand for this separate internal language.

The delivered workflow turns supplied before/after JSON into effective added/removed requests with concrete evidence, an exact costed local proposal over the specified deletion universe, a new JSON model and a checker result. The selected deny-diamond edit changes the approval decision: zero-cost membership/edge removals look attractive but are rejected because they create forbidden secret access. The cost-trap result chooses one cost-3 inheritance deletion instead of cost-4 greedy grant deletions, preserving report reading. These are measured synthetic decisions, not incident reduction estimates.

Costs are user-entered integers (e.g. approval units or change effort), not dollars. Conditional economics: if an engineer would otherwise inspect M candidate deletions manually for t minutes each, enumeration/evidence could replace part of M×t review minutes. Neither M nor t is measured here. Integration requires explicit model export and application owner validation; no connector, customer, adoption, revenue or willingness to pay is established. Error consequences and inventory maintenance can dominate any hypothetical savings.

Sustainable scope is a small MIT library/CLI, strict JSON schema, two evaluators, bounded search and synthetic regression cases. No paid-support promise, regulatory certification or cloud compatibility claim is made. A useful pilot should compare a real internal application's exported decisions with its own engine before using suggestions in approval; AccessDelta never applies account changes.
