# Security reporting and boundary

Report a minimal synthetic model, exact package/commit, command and observed/expected decision via the repository's private vulnerability reporting if enabled; otherwise contact the maintainer through the public repository without secrets, identities, real permissions or tokens. A public repository/contact channel is not yet established in this local build.

This package evaluates supplied internal declarations. It cannot authenticate a permission inventory or certify undeclared identities/resources. Unsupported conditions/wildcards return UNKNOWN; malformed references/cycles return INVALID. Do not remove restrictions just to make an unsupported input parse. All proposed modifications are local JSON deletions. Keep source, proposal and rechecked output together, and require application-specific review before any real rollout.
