# Contributing

Use Python 3.11+ and ordinary `python -m pip install .`. Run `python -m unittest discover -s tests -v`, `python scripts/demo.py` and `python scripts/contrast.py`. The core has no runtime dependencies. Preserve strict unknown/ref/cycle errors, explicit-deny precedence and complete-candidate reevaluation. Changes to the internal language need examples, adversarial tests and independent oracle comparison, not cloud-language branding.

Keep baseline costs/data/constraints identical. Report counterexamples and baseline successes. Never infer optimality or uniqueness from a stopped search. Use synthetic fixtures, no secrets or production inventories. Keep text files LF. Each supported bug fix should include a frozen probe that fails on the direct parent and succeeds after the substantive correction.
